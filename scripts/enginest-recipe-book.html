Before you start

How to use this recipe book

This guide is a sequence of 30 prompts that rebuild the entire Enginest website from an empty folder to a live deployment. Each prompt is self-contained: you copy it, paste it into your AI assistant (Claude, ChatGPT, Cursor, etc.), apply the resulting code, and verify. Every prompt lists the file it creates, what the file does, and how to verify it worked.

The prompts are organized in 7 phases. Do not skip phases — each phase builds on the previous one. Phase 1 must come before Phase 2, and so on. Within a phase, prompts can sometimes be reordered, but follow the printed order for your first build.

Design tokens used throughout: Navy #0F1B3D, Blue #3B82F6, Soft Blue #93C5FD, Blue tint #EFF6FF. Fonts: Inter (body), Playfair Display (italic accents), JetBrains Mono (code). When a prompt mentions "the Enginest palette", it means these colors.

Prerequisites: Node.js installed, VS Code installed, an empty project folder, an AI assistant open in a browser tab, and a terminal running. If you haven't done these yet, go back to Part I of this series before continuing.

A smart navbar that's transparent on the homepage (over the hero) and solid navy on inner pages when you pass <PublicNavbar solid />.
